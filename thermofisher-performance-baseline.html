Executive Summary

This report captures the pre-migration performance baseline for the ThermoFisher homepage (thermofisher.com/us/en/home.html). Establishing this baseline before any platform migration is critical — it provides a measurable reference point to quantify improvements, identify regressions, and demonstrate ROI to stakeholders. These metrics represent the current state of the site as experienced by real users and synthetic testing tools, serving as the benchmark against which all post-migration performance will be measured.

Disclaimer

Important Note: The metrics presented in this report are indicative and may vary under different circumstances. Lighthouse lab data is captured using simulated network throttling (Slow 4G for mobile, custom throttling for desktop) and emulated devices, which may not exactly reflect real-world conditions. CrUX field data represents a 28-day rolling average from Chrome users and can fluctuate based on traffic patterns, user demographics, device distribution, and network conditions. Scores should be used as directional benchmarks for comparison purposes rather than absolute performance guarantees. Multiple test runs may yield slightly different results due to server load, CDN caching state, third-party script behavior, and other dynamic factors.
